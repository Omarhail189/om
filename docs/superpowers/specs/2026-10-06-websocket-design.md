# اتصال أسعار مفتوح لشاشة om

المستخدم طلب WebSocket يجلب السعر مع كل رسالة، وheartbeat يبقي الاتصال قائمًا.
تنفيذ ونشر التعديل مصرح به مباشرة في المحادثة.

- --live يستخدم WebSocket افتراضيًا لأسعار GSPC أو TSLA؛ --transport poll يبقي
  الوضع السابق متاحًا. --refresh يخص تحديث شموع المؤشرات وليس سرعة السعر.
- endpoint Yahoo الحالي wss://streamer.finance.yahoo.com/?version=2، وبروتوكول
  JSON subscribe وPricingData protobuf الخاص بإصدار yfinance المثبت 1.7.0.
- Ping/Pong كل20 ثانية، مهلة Pong20، وإعادة الاشتراك كل15 كما في yfinance.
- reconnect مستقل بتراجع1،2،4… حتى60 ثانية وإعادة اشتراك بعد كل اتصال؛ تُعلّق
  التوصية أثناء الانقطاع. نجاح المصافحة/Pong لا يعني وصول سعر للرمز.
- السعر يحمل وقت المصدر وعمره. تُرفض الرسائل التالفة والسعر غير المحدود أو
  غير الموجب والتوقيت المستقبلي بأكثر من5 ثوانٍ؛ تُهمل الرسائل بغير الرمز
  أو أقدم من آخر سعر مقبول. مرور30 ثانية على وقت السعر يجعله متأخرًا.
- الشموع المغلقة الأصلية مصدرها Yahoo history مستقل في background daemon؛
  لا تُخترع شموع أو أحجام من quote ticks. السعر يتحدث حتى لو تعذر تنزيل history،
  ولكن التوصية تحتاج السعر الحديث واتصالًا مفتوحًا ومؤشرات شمعة حديثة.
- العرض يستجيب لرسائل السعر ويفحص الوقت كل ثانية؛ طلب history لا يحجب الشبكة
  أو Ping/Pong أو السعر. CPU تحليل الشموع لا يتكرر عند كل tick.
- Ctrl+C يغلق WebSocket ويلغي المهام؛ thread HTTP الخاص بالمشروع daemon ولا
  يؤخر خروج asyncio. لا تغييرات على المواقع أو MT5 أو الخدمات الأخرى.
- تختبر الشبكة محليًا بمخدم WebSocket حقيقي وprotobuf حقيقي في اختبارات معزولة؛
  الفحص الخارجي يُوصف بدقة، بلا أسعار بديلة أو ضمان استمرار الاتصال مطلقًا.
