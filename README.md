# om — تحليل البيانات والمؤشرات والإشارات

مشروع Python بواجهة طرفية. المسار التشغيلي المكتمل:

`CSV → التحقق من البيانات والتوقيت → المؤشرات → OpeningStrategy → التقارير`

نقطة التشغيل الرسمية: `main.py`. التشغيل الافتراضي محلي على بيانات GSPC
الموجودة في المستودع، دون اتصال بالإنترنت أو مفتاح API.

## شاشة التوصيات المستمرة في الترمينال

للنسخة الموجودة عندك على كالي:

```bash
cd /home/om/om &&
git pull --ff-only &&
bash setup.sh &&
bash run.sh --live --symbol GSPC
```

للتشغيل لاحقًا من أي مجلد، دون الحاجة إلى تفعيل البيئة يدويًا:

```bash
bash /home/om/om/run.sh --live --symbol GSPC
```

تبقى الشاشة مفتوحة وتفحص Yahoo كل **60 ثانية**. تعرض السعر عند آخر إغلاق،
ووقت آخر شمعة بنيويورك، وعمر البيانات، والتوصية الحالية وأسبابها ونقاطها،
وRSI وRVOL وATR وVWAP، وسجل آخر الإشارات. للإيقاف اضغط **Ctrl+C**.
تُحدّث الشاشة نفسها في الطرفية العادية؛ عند حفظ stdout تظهر تحديثات نصية دون ANSI.
يتحدث وقت العرض وحالة صلاحية التوصية كل ثانية، مستقلًا عن فترة جلب المصدر.
أثناء طلب الشبكة تظهر حالة الجلب وتُعلّق التوصية حتى انتهاء الفحص.

```bash
# TSLA، أو تقليل عدد صفوف السجل وتغيير فترة الفحص
bash run.sh --live --symbol TSLA --rows 5 --refresh 60
```

الوضع المستمر يستخدم شموع **1m المغلقة فقط**، من فترة 5d افتراضيًا لتهيئة
المؤشرات. هذا تحديث دوري لشموع Yahoo، وليس بث أسعار tick أو ضمان عدم تأخر المصدر.
يظهر السعر عند إغلاق الشمعة، لا السعر الجاري داخل الدقيقة.
أثناء الوقت المعتاد للجلسة، إذا تجاوز عمر **نهاية** آخر شمعة 180 ثانية تُعلّق
التوصية ويظهر التأخر. خارج أيام الاثنين–الجمعة 09:30–16:00 نيويورك يظهر انتظار
الجلسة؛ هذا فحص للوقت المعتاد وليس تقويم عطلات. بيانات العطلات تُكشف كتأخر إذا
كان الوقت ضمن هذه النافذة. أوقات الاستراتيجية الأصلية أضيق من نافذة الجلسة.

عند انقطاع الشبكة أو منع Yahoo للطلبات تُعلّق التوصية، وتبقى آخر البيانات كسجل
مع وقتها، وتُعاد المحاولة تلقائيًا بفترات متزايدة حتى 900 ثانية. لا تُعرض بيانات
CSV القديمة بدل المصدر، ولا تُكتب ملفات CSV وتقارير كاملة عند كل فحص.
`--refresh` يقبل 30–900 ثانية؛ `--live` لا يجتمع مع `--input` أو `--download`
ولا يقبل `--interval` غير 1m. لا يوجد تنفيذ صفقات أو تدريب/اختبار ربحية.

## التثبيت على كالي / لينكس

المتطلبات الأساسية للتجهيز: Git وPython 3 مع `pip`، واتصال بالإنترنت لتثبيت الاعتماديات.
المشروع يستخدم Python **3.11 أو 3.12 أو 3.13**؛ لا يلزم أن يكون أحدها مثبتًا مسبقًا
إذا استخدمت مسار التنزيل التلقائي. النسخة المثبتة التي يختارها السكربت يجب أن تدعم `venv`.
الإصدارات المباشرة للمكتبات مثبتة في `requirements.txt`؛ تم اختبارها على Python 3.12.

لنسخة جديدة داخل `/home/om/om`:

```bash
git clone --branch main https://github.com/Omarhail189/om.git /home/om/om
cd /home/om/om
bash setup.sh
bash run.sh --symbol GSPC
```

إذا كانت لديك نسخة سابقة، ادخل مجلدها ونفذ `git pull --ff-only` ثم `bash setup.sh`.
لا تستبدل نسخة تحتوي تعديلات محلية.

ينشئ `setup.sh` البيئة `.venv` داخل المشروع ويثبت الاعتماديات فيها فقط.
يختار تلقائيًا Python مدعومًا من البيئة الموجودة أو الإصدارات المثبتة.
إذا كان Python الافتراضي غير مدعوم ولم يجد إصدارًا مناسبًا، يجهز `uv`
داخل `.bootstrap` وينزّل Python 3.12 داخل `.python` ثم ينشئ `.venv`.
هذه الخطوة تحتاج الإنترنت، ولا تستبدل Python النظام ولا تعدل PATH العام.
مرجع تنزيل Python: [توثيق uv](https://docs.astral.sh/uv/guides/install-python/).
لتحديد نسخة مثبتة بنفسك، مثلًا:

```bash
OM_PYTHON=python3.12 bash setup.sh
```

إذا ظهر أن `venv` أو Git غير مثبتين على كالي:

```bash
sudo apt update
sudo apt install git python3-venv python3-pip
```

## اختيار المصدر

```bash
# TSLA من الملفات المحلية
bash run.sh --symbol TSLA

# ملف محدد؛ المسار النسبي يُحسب من مجلد الطرفية الحالي
bash run.sh --symbol GSPC --input data/raw/GSPC_20260726_190400.csv

# ملف خارجي بلا منطقة زمنية: حدد منطقة توقيته الأصلية
bash run.sh --symbol GSPC --input /path/to/prices.csv --timezone America/New_York

# تنزيل بيانات حديثة ثم تحليلها؛ هذا الخيار يحتاج الإنترنت
bash run.sh --symbol GSPC --download --period 5d --interval 1m

# موقع النتائج وعدد الصفوف المعروضة
bash run.sh --symbol GSPC --output-dir /home/om/om/reports --rows 20

# الخيارات
bash run.sh --help
```

الرمزان المدعومان: `GSPC` (أو `^GSPC`) و`TSLA`. عند عدم تحديد `--input`،
يختار البرنامج أحدث ملف **حسب تاريخ التعديل** داخل `data/raw` وبادئة الرمز المطلوب.
لا يختار TSLA عند طلب GSPC. يُرفض الملف إذا كان رمزه الداخلي يخالف الرمز المطلوب.
الملفات ذات الرأس الواحد يمكنها حمل عمود `Symbol`؛ إذا غاب، فالرمز يحدده المستخدم.

الملفات المرفقة تغطي **16–24 يوليو 2026**؛ التشغيل المحلي عليها تحليل تاريخي.
`--download` يعتمد على توفر Yahoo وقيوده، ولا يتحول البرنامج تلقائيًا إلى البيانات القديمة عند فشل التنزيل.
مرجع خيارات التنزيل: [توثيق yfinance](https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html).

## صيغة البيانات والتوقيت

يقبل البرنامج CSV برأس واحد، أو تنسيق Yahoo ذي أسطر `Price / Ticker / Datetime`.
الأعمدة المطلوبة:

`Datetime, Open, High, Low, Close, Volume`

يقبل `Date` أو `Timestamp` بدل `Datetime`. يجب أن يمثل كل ملف رمزًا واحدًا.
الأسعار موجبة، والحجم غير سالب، وHigh/Low متسقان مع Open/Close.
تُرفض القيم المفقودة وغير الرقمية وغير المحدودة، والشموع ذات التوقيت المكرر.
تُرتب البيانات زمنيًا قبل حساب المؤشرات؛ لا تُحذف الصفوف التالفة بصمت.

التوقيت الذي يتضمن منطقة زمنية يُحول إلى UTC مرة واحدة.
التوقيت المحلي بلا منطقة يُفسر حسب `--timezone` (الافتراضي نيويورك).
خلط توقيت محلي وتوقيت ذي منطقة زمنية يُرفض. أوقات الانتقال الصيفي الملتبسة تحتاج توقيتًا صريحًا.

يلزم 200 شمعة على الأقل لحساب EMA_200. تُستبعد شموع تهيئة المؤشرات
والشموع التي لا يمكن حساب مؤشرات الحجم لها؛ العدد المستبعد ظاهر في التقرير.

## النتائج

كل تشغيل ناجح ينشئ مجلدًا مستقلًا داخل `reports/<SYMBOL>_<UTC_TIMESTAMP>/`:

- `signals.csv`: الأسعار والمؤشرات و`SCORE` و`SIGNAL` و`REASON`.
- `summary.json`: المصدر، بصمة SHA256، أعداد الشموع والإشارات والفترة المحللة بتوقيت UTC.
- `report.txt`: ملخص عربي قابل للقراءة.

تظل ملفات المصدر والنتائج السابقة كما هي. تظهر المسارات الكاملة في الطرفية.
فشل المدخلات أو الاعتماديات يُرجع كود خروج غير صفر ورسالة توضح السبب.

## الاستراتيجية والنطاق

منطق `OpeningStrategy` الأصلي محفوظ: شروط اتجاه وزخم وحجم، وأوقات نيويورك
09:30–13:00 و15:00–16:00، مع منع تكرار إشارة الشراء لمدة 10 شموع.
`SCORE` مجموع نقاط الشروط (قد يصل إلى 110)، وليس نسبة ثقة أو احتمال نجاح.
VWAP الحالي متحرك بنافذة 14 شمعة كما في مكتبة `ta`؛ ليس VWAP متراكمًا منذ افتتاح الجلسة.
RVOL نسبة الحجم إلى متوسط آخر 20 شمعة. الاستراتيجية تنتج إشارات شراء ومراقبة فقط.

هذه النسخة جاهزة لمسار التحليل والإشارات والتقارير. ملفات `ai/trainer.py` و`ai/predictor.py`
و`backtesting/engine.py` و`strategies/middle.py` و`strategies/closing.py` باقية كهياكل فارغة
خارج المسار التشغيلي؛ لا يوجد تدريب أو اختبار ربحية أو تداول آلي في هذه النسخة.
`jp.ovpn` ملف موجود سابقًا وغير مستخدم في التشغيل.
